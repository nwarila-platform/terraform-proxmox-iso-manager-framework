# Graph Artifacts

Graph artifacts are generated from local-source Terraform fixtures. They are designed to
show dependency shape without storing state, raw plan files, credentials, or unredacted plan
JSON.

## File Names

| Pattern | Description |
|---|---|
| `*.validate.json` | Machine-readable output from `terraform validate -json`. |
| `*.plan.dot` | DOT graph from `terraform graph -type=plan -draw-cycles`. |
| `*.plan.svg` | SVG rendering of the DOT graph via Graphviz `dot -Tsvg`. |
| `*.cycles.json` | Cycle report from `tools/tf_graph_cycles.py`. |
| `*.summary.json` | Summary report from `tools/tf_graph_summary.py`. |
| `graph-diff.json` | Deferred future artifact for comparing graph summaries across releases. |

## Summary JSON Schema

`*.summary.json` contains:

| Field | Type | Description |
|---|---|---|
| `fixture` | string | Fixture directory used as the Terraform root module. |
| `terraform_graph_type` | string | Terraform graph type. Current value is `plan`. |
| `nodes` | number | Count of unique DOT nodes. |
| `node_count` | number | Alias of `nodes` for release evidence tools that expect count-suffixed fields. |
| `edges` | number | Count of directed DOT edges. |
| `edge_count` | number | Alias of `edges` for release evidence tools that expect count-suffixed fields. |
| `cycle_count` | number | Number of detected cyclic components and self-loops. |
| `cross_module_edges` | number | Count of edges that connect objects across module boundaries. |
| `generated_from` | string | Command used to generate the DOT graph. |

## Cycle JSON Schema

`*.cycles.json` contains:

| Field | Type | Description |
|---|---|---|
| `dot_file` | string | DOT file analyzed. |
| `node_count` | number | Count of unique DOT nodes. |
| `edge_count` | number | Count of directed DOT edges. |
| `cycle_count` | number | Count of cyclic components and self-loops. |
| `cycles` | array | List of detected cycles, each with `type` and `nodes`. |

## Deferred Graph Diff Schema

`graph-diff.json` is reserved for future release comparison. When implemented, it should
compare two summary files and report:

| Field | Type | Description |
|---|---|---|
| `base_fixture` | string | Baseline fixture name. |
| `head_fixture` | string | Compared fixture name. |
| `node_count_delta` | number | Difference in node counts. |
| `edge_count_delta` | number | Difference in edge counts. |
| `cycle_count_delta` | number | Difference in cycle counts. |
| `cross_module_edges_delta` | number | Difference in cross-module edge counts. |
